# 指令说明（KOOK + QQ 官方机器人）

> 本插件同时支持 **KOOK** 与 **QQ 官方机器人**两个平台。两个平台的「怎么发指令」差别很大，本文档把用法、平台限制、以及各平台「按钮/面板」能怎么配一次说清。
>
> 相关：QQ 官方机器人的指令面板 / 单聊菜单 API 细节见 [`qqofficial-commands.md`](./qqofficial-commands.md)。

---

## 一、两个平台怎么发指令（最容易搞错的地方）

| | KOOK（频道 / 私聊） | QQ 官方机器人（群 / 私聊） |
| --- | --- | --- |
| 发指令方式 | **直接发 `/指令`**，不需要 @ | **发 `/指令` 即可**（带 `/` 前缀就会响应）；`@机器人 /指令` 也行 |
| 裸指令（不带 `/`、不 @） | 不响应 | 不响应（会回一句提示"请带 `/` 前缀或 @机器人"） |
| 消息内按钮 | ✅ 有（卡片消息按钮 / 指令面板） | ❌ 无（个人认证拿不到"消息按钮模板"能力） |
| 私聊 | ✅ 可用（可私发验证码/关联码） | ❌ 个人认证不可用（"允许被其他 QQ 用户添加使用"仅对企业开发者灰度开放） |
| 界面上的"按钮" | 卡片消息按钮、开发者后台的指令面板 | 开放平台 API 的指令面板；群设置里的入群欢迎按钮（零代码） |
| 快捷输入 | `/菜单` + `/1`～`/6` | `/菜单` + `/1`～`/6`（QQ 侧的主力方案） |

**一句话**：两边都记「`/` + 指令」；KOOK 更省心（不用 @、有真按钮），QQ 个人认证下只能靠文本 + 编号菜单 + 指令面板。

> 原理：AstrBot 的 `wake_prefix` 为 `/`，群聊里**以 `/` 开头**的消息就会唤醒机器人（仅当首段是 @ 别人时不唤醒），所以"裸指令"不生效。

## 二、指令总表

### 查询类
| 指令 | 说明 | 备注 |
| --- | --- | --- |
| `/在线玩家` | 在线人数 + 部落 | 可加 `进化`/`飞升`、地图名 |
| `/进化`、`/飞升` | 服务器状态 | 不带地图名 = 列全部 |
| `/查服` | 按 IP 或地图名查服 | 通用查询 |
| `/状态` | 各服务器在线 / 离线一览 | 上下线也会自动提醒 |
| `/倍率` | 当前动态倍率 | |
| `/直连` | 所有地图直连地址 | 唯一会显示地址的指令 |

### 账号类
| 指令 | 说明 | 备注 |
| --- | --- | --- |
| `/绑定 进化 <SteamID64>` | 直接绑定（进化，17 位数字） | 不需要私聊 |
| `/绑定 飞升 <EOS 32位ID>` | 直接绑定（飞升） | **EOS 在商店页面就能看到**，不需要私聊 |
| `/我的ID` | 查自己的身份 ID | 用于 `/关联` 打通多平台、找管理员核对身份 |

| `/查绑定` | 查看我的绑定 | 公共区域自动打码 |
| `/签到` | 每日领点数 | 各游戏每天一次 |
| `/关联` | QQ ↔ KOOK 身份打通 | `/关联 开码` → 另一平台 `/关联 <码>` |

## 三、KOOK：按钮怎么配

### 方式 1：开发者后台的「指令面板」
KOOK 开发者后台 → 机器人 → **指令面板 / 消息面板** → 新建 → 逐条添加（指令名 + 一句话说明）。
> KOOK 目前**没有**提供指令面板的开放 API，只能在后台页面配置。

推荐条目：`/在线玩家`、`/状态`、`/签到`、`/查绑定`、`/直连`、`/菜单`、`/帮助`。

### 方式 2：卡片消息按钮（可编程，插件里可用）
KOOK 卡片消息（发送类型 `10`）支持 `action-group` 模块，最多 4 个 `button`：

```json
[{"type":"card","theme":"primary","modules":[
  {"type":"header","text":{"type":"plain-text","content":"指令菜单"}},
  {"type":"action-group","elements":[
    {"type":"button","theme":"primary","click":"return-val","value":"/在线玩家","text":"在线玩家"},
    {"type":"button","theme":"primary","click":"return-val","value":"/状态","text":"状态"},
    {"type":"button","theme":"primary","click":"return-val","value":"/签到","text":"签到"},
    {"type":"button","theme":"primary","click":"return-val","value":"/查绑定","text":"查绑定"}
  ]}
]}]
```
发送：`POST https://www.kookapp.cn/api/v3/message/create`，body `{"target_id":"<频道或用户ID>","type":10,"content":"<上面的 JSON 字符串>"}`，头带 `Authorization: Bot <token>`。

> `click: "return-val"` 时 KOOK 会把「消息 id + 点击用户 id + value」通过按钮点击事件回传给机器人；
> `click: "link"` 则只是打开 `value` 里的链接。

## 四、QQ 官方机器人：面板与按钮

| 手段 | 怎么配 | 限制 |
| --- | --- | --- |
| 指令面板 | `POST /v2/panels`（详见 [`qqofficial-commands.md`](./qqofficial-commands.md)） | 元素 `name` ≤14 字符、`desc` ≤30 字符 |
| 单聊自定义菜单 | `PUT /v2/menu` | 仅单聊；个人认证通常进不了单聊，形同虚设 |
| **消息内按钮（键盘）** | 需先在开放平台申请「消息按钮模板」并审核，通过后用 `keyboard={"id":"<模板id>"}` 发送（插件已预留配置 `qq_keyboard_template_id`） | 个人认证可能不开放 |
| 群设置「入群欢迎 + 自定义按钮」 | QQ 群设置 → 群机器人 → 入群欢迎 | 零代码，**按钮文本必须带 `/`**，否则点击不触发 |

**入群欢迎按钮建议文本**：`/在线玩家`、`/签到`、`/查绑定`、`/帮助`、`/帮助 查询`。

## 五、游戏内公屏指令（不属于 QQ/KOOK 指令）

| 指令 | 说明 |
| --- | --- |
| `zsbind <验证码>` | 先在 QQ/KOOK 里发 `/绑定 <游戏> 开绑` 拿 6 位验证码，再到游戏公屏发这一行 → 完成绑定 / 换绑 |

> 由机器人读取**游戏聊天记录**处理，不需要在 QQ/KOOK 侧登记。
> 另：早期还有 `qqbind <身份ID>` 通道（游戏公屏直接贴 `/我的ID` 那串），因为要在公屏暴露身份 ID，已**默认停用**（`game_bind.qq_cmd=false`），需要时置 `true` 可恢复。

## 六、注意事项

1. **群与私聊是两个身份**（openid 不同）：两边都能绑，但要 `/关联` 打通才能共用绑定与点数。
2. **同一游戏账号每天只加一次点数**：两边都签到也不会双倍。
3. **隐私**：群/频道里所有 ID 一律打码，只有私聊才给完整；`/状态`、上下线提醒只显示服务器名，不显示地址。
4. **没装 ArkShop 插件的服**：在 `arkshop_exclude_servers` 里按名字子串配置，加点与倍率刷新命令会自动跳过它们。
5. **消息互通**：`bridge_enabled` 打开后，配置里的 QQ 群与 KOOK 频道之间互通，游戏内聊天也会同步到这些位置。
