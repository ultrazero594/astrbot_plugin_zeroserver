# QQ 官方机器人「指令」登记清单

> 本文件用于在 [QQ 开放平台](https://q.qq.com) 为机器人登记「指令」（资料页/指令面板展示与推荐用）。
> 登记**不影响**指令实际收发——只要机器人能收到消息，插件就会响应；登记只是让玩家知道能发什么。

## 一、去哪登记

1. 浏览器打开 **https://q.qq.com** 并登录（用机器人所属的 QQ 号）；
2. 进入 **机器人** 列表，选中你的机器人（如 `ZeroARKBot`）；
3. 在左侧菜单找 **「指令」**（不同版本可能在 **开发设置 → 指令** 或 **功能配置 → 指令** 下；找不到就用页面内搜索“指令”）；
4. 点 **新增指令**，按下表填写三列：**指令名 / 指令说明 / 示例**；
5. 需要的话勾选 **“需要 @机器人”**（推荐勾选，与本插件群内使用方式一致）；
6. 保存；**公域机器人**通常需提交审核后才会在资料页展示，**沙箱/私域**一般即时生效。

> 指令名**不带 `/`**：填 `帮助`，玩家发 `帮助` 或 `/帮助` 都能触发（AstrBot 会自动处理前缀）。

## 二、玩家指令（权限：全部用户）

| 指令名 | 指令说明 | 示例 |
| --- | --- | --- |
| 帮助 | 查看全部指令与用法 | @机器人 帮助 |
| 进化 | 查询进化(ASE)服务器；不带地图名=列出全部进化服 | @机器人 进化 孤岛 |
| 飞升 | 查询飞升(ASA)服务器；不带地图名=列出全部飞升服 | @机器人 飞升 |
| 查服 | 通用查询：按 IP:端口 或地图名查询 | @机器人 查服 孤岛 ASA |
| 倍率 | 查看服务器当前动态倍率 | @机器人 倍率 |
| 直连 | 查看所有地图直连地址 | @机器人 直连 |
| 更新地址 | 手动刷新服务器地址缓存 | @机器人 更新地址 |
| 在线玩家 | 查看在线玩家与部落名；可指定版本/地图 | @机器人 在线玩家 飞升 孤岛 |
| 绑定 | 绑定游戏账号（进化=SteamID64 / 飞升=EOS）；发“开绑”可获取游戏内验证码 | @机器人 绑定 飞升 开绑 |
| 解绑 | 解除某个游戏的账号绑定 | @机器人 解绑 飞升 |
| 查绑定 | 查看自己已绑定的游戏账号 | @机器人 查绑定 |
| 签到 | 每日签到领点数（进化/飞升每天各一次） | @机器人 签到 |
| 我是谁 | 查看自己的平台 ID 与群标识（配置/排查用） | @机器人 我是谁 |

英文别名（如需要可另建条目，或写在说明里）：`help` / `ase` / `asa` / `ark` / `rate` / `direct` / `update_address` / `players` / `bind` / `unbind` / `mybind` / `signin` / `whoami`。

## 三、管理员指令（权限：管理员，仅私聊生效）

| 指令名 | 指令说明 | 示例 |
| --- | --- | --- |
| rcon | 对指定服务器 / 版本执行 RCON 命令 | /rcon ASA listplayers |
| 加点 | 给玩家添加 ArkShop 点数（单台在线服执行一次） | /加点 飞升 <EOS> 50 |
| 代加点 | 群聊中给已绑定的群友加点 | @机器人 代加点 进化 50 @某群友 |
| 测试推送 | 在通知群主动发一条测试消息（验证主动消息权限） | /测试推送 |

## 四、不用登记到平台的指令

| 指令 | 原因 |
| --- | --- |
| `qqbind <QQ号>`、`zsbind <验证码>` | **游戏内公屏指令**，由机器人读取游戏聊天库处理，不属于 QQ 侧指令 |
| `/points`、`/shop`、`/buy` 等 | 游戏内 ArkShop 插件的指令，本机器人不处理 |

## 五、填写小贴士

1. 平台若限制字数，优先保指令名，说明可精简为 2–4 字（如“查进化服”）；
2. 别名不必逐条登记，可在对应条目说明里带一句（如“也可用 /players”）；
3. QQ 官方机器人**拿不到真实 QQ 号**：绑定主键是 openid（私聊 `user_openid` / 群 `member_openid`，本机器人实测两者一致）；
4. 群内使用建议统一 **@机器人 + 指令**；群设置需开启“获取群内全部消息”与“机器人主动在群聊内发言”。
